# Projet HTML minimal

Ce dépôt contient une page HTML de base, prête à être personnalisée.

## Structure

```text
.
├── index.html
└── README.md
```

## Utilisation

Ouvrez [`index.html`](index.html) directement dans un navigateur, ou lancez un serveur local depuis le dossier du projet :

```bash
python -m http.server
```

Puis rendez-vous sur <http://localhost:8000>.

- HTML5
